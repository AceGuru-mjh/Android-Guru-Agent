### 教训
- 本地无 gradlew/Android SDK，无法端到端编译验证，只能静态核对 + 依赖 GitHub Actions。
- 改领域模型（如 SkillManifest）后必须全局搜索所有调用点。
- 分支操作（checkout/reset/stash）混乱会导致修复 commit 丢失，最终用 `git reset --hard origin/<branch>` + `git cherry-pick` 干净重建。
- `kotlinx.serialization`：在 Compose/屏幕层若未导入顶层 reified `encodeToString`，`Json.encodeToString(instance)` 会解析到非 reified 重载而要求显式 `SerializationStrategy`——显式传 `.serializer()` 最稳。
- 看 CI 失败日志用 `gh run view <id> --log-failed` 重定向到文件再读（PowerShell 无 tail，且 Get-Content 需 -Encoding）。
