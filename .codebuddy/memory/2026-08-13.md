## 代码审查修正（2026-08-13 续）
- 审查发现并修正 3 处真实缺陷（非功能缺口，是已落地代码的 bug/隐私问题）：
  1. **重复导航 bug**（`BrowserAgentTools.navigate`）：`new_tab=true` 时 `newTab(url)` 已加载 url 又紧跟 `navigate(url)` 二次加载。改为 `newTab(null)` 建空标签后由 `navigate` 统一负责加载+waitFor+超时兜底。
  2. **敏感权限自动授予**（隐私问题，`BrowserEngine.onPermissionRequest`）：原代码摄像头/麦克风直接 `request.grant(resources)` 且注释称"由用户决定",自相矛盾且未经用户确认即授予敏感权限。改为 deny + 进入人工接管(`enterHandoffMode`),提示用户用 `browser_show` 在真实页面授权（与 geolocation 一致,隐私最小化）。
  3. **STEALTH_JS 过度伪装**（`BrowserEngine`）：原 `navigator.plugins` 伪造为 `[1,2,3,4,5]` 数字数组,反爬若查 `plugins[0].name` 即暴露且可能破坏依赖 plugins 的页面。移除该覆盖,仅保留 `webdriver` 隐藏与 `languages` 微调（求稳、不过度伪装）。
- 两文件 lint 0 错误。现有测试（BrowserTracerTest/RetryPolicyTest）未覆盖 WebView 行为层，纯单测需 Robolectric，未新增（基础设施缺 WebView mock）。
