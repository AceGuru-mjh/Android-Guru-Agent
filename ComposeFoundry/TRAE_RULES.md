# ComposeFoundry TRAE Rules

## Project Structure
- Keep the project structure exactly as defined
- Do not add or remove files unless explicitly instructed
- All Kotlin files must be in `app/src/main/java/com/foundry/preview/`

## Code Style
- Follow Kotlin conventions
- Use 4 spaces for indentation
- Max line length: 120 characters

## Build Requirements
- Always use Gradle 8.2
- Compile SDK: 34
- Min SDK: 24
- Compose BOM: 2024.02.00

## File Writing Rules
1. When writing files, use exact content provided
2. Do not optimize or modify code unless asked
3. Preserve all comments and documentation

## Commit Messages
- Format: `type(scope): description`
- Types: feat, fix, chore, docs, refactor
- Scope examples: foundry, ui, dsl, engine
