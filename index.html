无需服务器，无需 PC，模型自己带（OpenAI 兼容接口）。

它不是聊天壳，是会动手的智能体。

每一项能力都有真实的执行管线在背后，不是提示词模拟。

真正的终端

PRoot 沙箱里跑完整的 Ubuntu 24.04，npx、python、git 在手机上可用。命令走真实进程，输出逐行流回上下文。

长任务自愈

限流、超时、网络断连自动退避重试；工具连续失败时，引擎注入换路提示，让模型换工具、换参数、换方法——任务不轻易死掉。

认知记忆

cs-mem 把重复操作蒸馏成可回放的肌肉记忆：第二次干同样的事，直接旁路执行，更快。

MCP 生态

官方 Hub 与 mcp.so 社区目录一键安装 MCP 服务器，本地沙箱运行，工具自动注册进引擎。

你掌握一切

Root、Shizuku、无障碍三级权限链；每一步执行可见、可中断。API Key 与会话数据只存在你的设备上。

内核是什么做的。

工程上较真，才敢把“自主执行”放进你的手机。

14个 Gradle 模块

引擎、LLM 适配、工具注册表、编码工作区、终端运行时各司其职；核心六模块纯 JVM，可直接单测。

1100+单元测试

任务运行时、编排器韧性、上下文压缩、市场解析全部有回归门禁，CI 红了就不合入。

6种执行模式

BUILD、CHAT、AGENT、PLAN、SPEC、REFLECTION 共享同一个 ReAct 主循环，按任务形态切换。

3架构 ABI

arm64、x86_64、v7a 全覆盖，Android 8.0 起步；PRoot rootfs 离线可装。
