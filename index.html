每一项能力都有真实的执行管线在背后，不是提示词模拟。

真正的终端

PRoot 沙箱里跑完整的 Ubuntu 24.04，npx、python、git 在手机上可用。命令走真实进程，输出逐行流回上下文；自研 VT100 模拟器纯 Kotlin 零依赖。

长任务自愈

限流、超时、网络断连自动退避重试；工具连续失败时，引擎注入换路提示，让模型换工具、换参数、换方法——任务不轻易死掉。

认知记忆

cs-mem 把重复操作蒸馏成可回放的肌肉记忆：第二次干同样的事，直接旁路执行，更快，不花 token。

双向 MCP 生态

当客户端：官方 Hub 仓库与 mcp.so 目录一键安装 MCP 服务器，npm 生态经沙箱接入，工具自动注册进引擎。当服务器：逆向 MCP Host 让 PC 上的 Cline / Claude 直接调用手机工具。

你掌握一切

Root、Shizuku、无障碍三级权限链；每一步执行可见、可中断。API Key 与会话数据只存在你的设备上，金库密钥绝不经外部通道出入。

问得最多的几件事。

完整版在 GitHub Wiki 的 FAQ 页；这里只放决定你要不要装的四条。

模型从哪来？要付钱给你们吗？

模型完全自带（BYO-LLM）：设置里填任意 OpenAI 兼容端点——OpenAI、DeepSeek、OpenRouter、中转站，或局域网 Ollama。应用本身免费开源，不经手任何模型费用；API Key 只存在设备私有目录的加密存储里。

为什么提示「应用针对旧版 Android 开发」？

这是预期的：项目钉死 targetSdk = 28。Android 10 起系统禁止应用从可写私有目录执行二进制，而 Ubuntu rootfs 依赖这条路径——Termux 至今钉 28 是同一个原因。升上去，终端就没了。

没有 Root 的手机能用多少？

全部功能可用，只是权限链自动降级：Root → Shizuku（ADB 级，免 Root 授权）→ 应用沙箱 shell。装 Shizuku 后 pm install、settings put、UI 自动化都能跑；什么都不装也有文件操作、终端沙箱和完整对话。

数据会上传到哪里？

只和你自己配置的 LLM 端点通信。会话、记忆库、密钥全在本地 Room 数据库与加密存储；无埋点、无统计、无云端账号。逆向 MCP Host 默认关闭，开启也仅限局域网 + Token 鉴权。
