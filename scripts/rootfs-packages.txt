# Apex Agent —— 完整 Ubuntu rootfs 包清单（构建 scripts/build_full_rootfs.sh 消费）
#
# 设计原则：
#  1. 「真 Ubuntu」而非 OEM 引导骨架 —— 官方 ubuntu-base 只有 bash/apt/dpkg 骨架
#     （28MB），Agent 拿到后连 curl/python/git 都没有。本清单把「开箱即用的
#     完整 CLI 工作环境」固化进构建期：解压后 ~1GB+、压缩档 ~300MB+（v1.3.0
#     产品红线：交付物不偷工减料），apt 仍可在线扩展。
#  2. 覆盖 BasePackageProfile.DEFAULT.essential + recommended 的全部包 —— 设备端
#     bootstrap 的 APT_UPDATE/BASE_PACKAGES 阶段被 dpkg-query 离线短路（T84），
#     本清单是其预装真值来源：清单与 essential 漂移会导致短路失效（回退联网
#     引导，功能不坏但离线体验退化）—— 漂移是显式变更，需同步两处。
#  3. 诚实取舍：不装 manpages-posix（2MB×大量重复，dev 手册够用）；
#     不装 golang（~250MB 解压占用量级过大，apt 按需装）；
#     不装 rustc/default-jdk/ffmpeg 等重型运行时（同上，apt 在线扩展）。
#
# 分组仅注释可读，安装时全部展开传给 apt-get（--no-install-recommends）。
